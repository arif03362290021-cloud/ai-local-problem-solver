## 📖 About The Project
In Pakistan, especially in remote areas, students face lack of quality teachers, expensive academies, language barriers, and no personal guidance. This project is an AI-based local problem solver focused on education that provides 24/7 affordable tutoring in simple Urdu, Roman Urdu, and English.

This is my **Final Hackathon Project**.

## 🎯 Problem Statement
- No access to quality teachers in villages / small cities
- Most AI tools are in difficult English
- Expensive tuition and academies
- No career guidance according to local market

## 💡 Solution We Provide
- 24/7 AI Tutor - Ask any educational question
- Explains in Urdu, Roman Urdu & English
- Notes Generator, Summaries, and Exam Prep
- MCQs, Past Papers & Quiz Practice
- Career & Skill Guidance for Pakistani students

## ✨ Key Features
- 🗣️ Multilingual Support (Urdu / Roman Urdu / English)
- 📚 Covers Matric to BS Level Subjects
- 📝 Smart Notes & Summary Generator
- ❓ Test Preparation System
- 💼 Career Counseling
- 📱 Fast & Responsive UI

## 🛠️ Tech Stack
**Frontend:** React, TypeScript, Vite, Tailwind CSS, HTML5
**Backend:** Node.js, Express.js (server.ts)
**AI:** OpenAI API / LLM Integration
**Tools:** Git, GitHub, VS Code
